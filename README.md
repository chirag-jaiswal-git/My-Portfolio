## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)

### Installation

```bash
# Clone the repo
git clone https://github.com/chirag-jaiswal-git/My-Portfolio.git
cd My-Portfolio

# Install dependencies
npm install
```

### Run locally

```bash
npm run dev
```

The site should now be running at `http://localhost:5173`.

### Build for production

```bash
npm run build
```
